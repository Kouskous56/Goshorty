## 1. Kiến trúc tổng quan

```
main.go  ───→  config/  ───→  ServerConfig, TTLConfig
                ↓
          storage/  ───→  Storage (in-memory URL store + cleanup goroutine)
                            UserStorage (in-memory user store)
                ↓
          services/ ───→  URLService (business logic)
                            TokenService (HMAC-SHA256 token)
                ↓
          handlers/ ───→  Handler (URL CRUD HTTP handlers)
                            AuthHandler (auth HTTP handlers + middleware)
                ↓
          models/   ───→  URLData, ShortenRequest/Response, User, Login/Register, ErrorResponse
                ↓
          utils/    ───→  GenerateID, GenerateShortCode
                ↓
     static/index.html ───→  Frontend SPA (vanilla JS, ~1050 LOC)
```

### Luồng request điển hình

```
POST /api/shorten
  → AuthMiddleware (verify token từ Authorization header)
    → CreateShortURL (handler)
      → URLService.CreateShortURL (validate URL scheme, TTL, generate code)
        → Storage.Set (lưu entry với ExpiresAt)
          ← ShortenResponse { short_url, short_code, expires_in, ... }
```

### Luồng redirect

```
GET /goshorty/24h/abc123
  → Redirect (handler)
    → URLService.GetOriginalURL (gọi Storage.GetAndIncrement - atomic)
      → c.Redirect(302, originalURL)
```

### Luồng cleanup

```
Storage.cleanupExpired() goroutine
  → ticker 30s
    → select: stop channel (shutdown) | ticker (cleanup)
      → Lock → delete expired entries → Unlock
```

## 3. Packages chi tiết

### 3.1 `config/` (59 lines)

| Export | Type | Description |
|--------|------|-------------|
| `Config` | struct | ServerConfig + TTLConfig |
| `ServerConfig.Port` | string | `":8080"` (từ `PORT` env) |
| `ServerConfig.BaseURL` | string | `"http://localhost:8080"` (từ `BASE_URL` hoặc `PORT` env) |
| `TTLConfig.Options` | map | `{"5m": 5min, "15m": 15min, "1h": 1h, "24h": 24h, "168h": 7d}` |

- `portFromEnv()`: nếu `PORT` set → `":" + PORT`, nếu không → default
- `baseURLFromEnv()`: ưu tiên `BASE_URL`, fallback `PORT`, fallback default

### 3.2 `models/` (2 files, 78 lines)

**`url.go`**: ShortenRequest (URL required+url, ExpiresIn oneof, CustomCode alphanum), URLData (ID, ShortCode, OriginalURL, ExpiresIn, ExpiresAt, CreatedAt, CreatedBy, Visits), ShortenResponse, ErrorResponse.

**`user.go`**: RoleAdmin="admin", RoleUser="user", User (ID, Username, Password=json:"-", Email, Role, CreatedAt), LoginRequest, LoginResponse, RegisterRequest.

### 3.3 `storage/` (2 files, 358 lines)

**`storage.go`**:
- `Storage`: `map[string]*StorageEntry` + `sync.RWMutex` + `stop chan`
- `GetAndIncrement`: atomic read+increment under single Lock (fix race condition)
- `cleanupExpired`: goroutine, select trên stop/ticker, Lock khi cleanup
- `Stats`: chỉ đếm entry chưa expired
- `Stop()`: close channel → cleanup goroutine exit

**`user.go`**:
- `UserStorage`: `map[string]*User` (by username) + `map[string]*User` (by ID)
- `NewUserStorage(adminPassword, adminEmail)` → trả về error, không panic
- `ErrUserNotFound` sentinel error
- `VerifyPassword`: bcrypt compare

### 3.4 `services/` (2 files, 284 lines)

**`url_service.go`**:
- `CreateShortURL`: validate scheme (http/https), TTL lookup, custom/generated code, Set
- `DefaultExpiresIn = "24h"` constant
- `GetOriginalURL`: gọi `GetAndIncrement` atomic
- `DeleteURL`: kiểm tra role/admin ownership
- `GetAllURLs`: admin thấy tất cả, user thấy URL của mình

**`token_service.go`**:
- `TokenTTL` var (24h default, configurable via `TOKEN_TTL` env)
- `GenerateToken`: JSON marshal → base64URL → HMAC-SHA256 → `payload.signature`
- `VerifyToken`: split, HMAC verify (constant-time), decode, check expiry

### 3.5 `handlers/` (3 files, 398 lines)

**`handler.go`**:
- `requireCode(c, code)` helper — tránh duplicate code check
- `Redirect`: 302 Found (tránh browser cache)
- `DeleteURL`: luôn trả về 404 — không leak URL existence
- Consistent error messages: `"URL not found or has expired"`

**`auth.go`**:
- `Register`: generic `"Registration failed"` — không leak username existence
- `Login`: generic `"Invalid credentials"` — không phân biệt wrong user vs wrong pass
- `AuthMiddleware`: generic `"Invalid or expired token"` — không leak lý do
- `GetCurrentUser`: kiểm tra error từ GetUserByID, không trả về nil user
- `AdminMiddleware`: standalone function, kiểm tra role

**`auth_test.go`**: 16 tests covering register, login, middleware, admin, user CRUD.

### 3.6 `utils/` (1 file)

- `GenerateID()`: 16-char hex string
- `GenerateShortCode(n)`: n-char alphanumeric string

Dùng `math/rand` với seed từ `time.Now().UnixNano()`. Acceptable cho short codes không phải security-critical.

## 6. Các vấn đề đã sửa (10 bước)

### Bước 1: URL format + Race condition
- **Bug**: `duration.String()` trả về `"24h0m0s"` thay vì `"24h"`
- **Bug**: Get + IncrementVisits không atomic → race condition
- **Fix**: Dùng `expiresInDisplay` fallback + `GetAndIncrement` dùng 1 Lock

### Bước 2: HMAC-SHA256 token signing
- **Bug**: Token là plain JSON, không có chữ ký → có thể forge
- **Fix**: `payload.signature` format, HMAC-SHA256 verify với `hmac.Equal`

### Bước 3: OwnerID + URL filtering
- **Bug**: `/shorten/all` trả về tất cả URL cho mọi user
- **Fix**: `CreatedBy` field + filter theo role

### Bước 4: XSS + API_BASE hardcode
- **Bug**: User data inject vào innerHTML → XSS
- **Bug**: `API_BASE = 'http://localhost:8080/api'` hardcode
- **Fix**: `escapeHtml()` + `JSON.stringify()` + relative path `/api`

### Bước 5: Bcrypt cho password
- **Bug**: SHA256 là fast hash (10^9 hash/s GPU), không salt
- **Fix**: `golang.org/x/crypto/bcrypt`, cost=10 (~100ms/hash)

### Bước 6: Graceful shutdown
- **Bug**: Cleanup goroutine leak, `router.Run()` block forever
- **Fix**: `stop chan` + `signal.Notify` + `srv.Shutdown(ctx)`

### Bước 7: Stats chỉ đếm active URLs
- **Bug**: Stats đếm cả expired URLs chưa cleanup
- **Fix**: Filter `now.After(entry.ExpiresAt)` trong Stats

### Bước 8: Dead code + Magic strings + Env vars
- Xóa `index` map dead code
- Constants: `RoleAdmin`, `RoleUser`, `DefaultExpiresIn`
- Env vars: `PORT`, `SECRET_KEY`, `ADMIN_PASSWORD`

### Bước 9: Fix CORS + Nil pointer + Auth tests
- CORS: xóa `Allow-Credentials` (vì `*` origin)
- Nil pointer: error check trong auth handlers
- 16 auth tests (register, login, middleware, admin CRUD)

### Bước 10: Refinement
- `NewUserStorage` return error (không panic)
- `SECRET_KEY` required (không fallback)
- URL scheme validation (chỉ http/https)
- Username enumeration fix
- URL existence leak fix
- Error message standardization
- `requireCode` helper, 302 redirect
- `BASE_URL`, `TOKEN_TTL`, `ADMIN_EMAIL` env vars
- Xóa dead code (`Host`, `UserStatsResponse`)
- Go comments cho exported types

- Port 8080 (mặc định)

| Variable | Required | Default | Description |

| `PORT` | No | `8080` | Server port |

| `ADMIN_PASSWORD` | No | `admin123` | Admin account password |
| `ADMIN_EMAIL` | No | `admin@goshorty.local` | Admin account email |

```powershell
# Development
$env:SECRET_KEY="my-secret-key-change-me"
go run .

# Production (example)
$env:SECRET_KEY="<random-64-char-hex>"
$env:ADMIN_PASSWORD="<strong-password>"
$env:BASE_URL="https://short.example.com"
go run .
```
